✨ What is an API?

An API is like a restaurant menu — you don't go into the kitchen, you order from the menu, and the kitchen brings your food.

①

Without an API

No rules — the customer barges in and everyone panics.

②

With an API: a menu

The menu is the API: what you can order, the format, what you get back.

③

Real example: weather app

The app doesn't need its own weather station — it just requests the data.

🎯 So, to recap

  • An API is a "menu" programs order from
  • It defines what you can ask, how, and what you get
  • No more "barging into the kitchen"

📖 Glossary

API
A "menu" for programs — it agrees on how to ask and what comes back
Request
A standard way one program asks another for something
Server
A computer that stores data and does work for others
