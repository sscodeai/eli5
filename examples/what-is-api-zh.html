✨ API 是什么?

API 就像餐厅的"点菜单"——你不用进厨房,照着菜单点菜,厨房就把菜端给你。

①

没有 API 的世界

没有规矩,客人只能闯进厨房,大家都乱套。

②

有了 API:一张菜单

菜单就是 API:写着你能点什么、要什么格式、能得到什么。

③

真实例子:天气 App

App 不必自己装气象站,按 请求 问一句就有答案。

🎯 所以,总结一下

  • API 是程序之间"点菜"的菜单
  • 它规定:你能问什么、怎么问、得到什么
  • 有了它,各家程序不用互相"闯厨房"

📖 术语表

API
程序之间"点菜"的菜单,约定了请求和返回的格式
请求(request)
一个程序向另一个程序"要东西"的标准问法
服务器
专门存数据、替别人干活的那台电脑
